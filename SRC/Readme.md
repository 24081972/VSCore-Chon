Para trabajar con texto en Git de forma profesional, se recomienda seguir buenas prácticas en los mensajes de commit,
 configurar un editor externo amigable, redactar un buen README.md 
 y explorar herramientas visuales basadas en texto como Tig. 
Los mensajes de commit deben seguir reglas de Midudev usando el imperativo y el formato de Conventional Commits.
By Chon Wilson
